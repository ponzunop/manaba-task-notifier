M manaba 課題通知システム Team 12 / 実メール連携対応
Gmail IMAPS / Gmail API × Web Push 連携

manaba の小テスト・課題締切を、あなたの実メールから自動取得。

ご自身の Gmail（大学アカウント等）に届いた manaba 通知メールをリアルタイムで解析し、 履修科目・小テスト名・公開時間・締切時間をそのまま取り込みます（ダミーデータは投入しません）。

方法①：Gmail から小テストを自動取得（推奨）

IMAPS (imap.gmail.com:993)

メールアドレスと Google 16桁アプリパスワード を入力すると、 ご自身の Gmail（imap.gmail.com）に接続して manaba の小テスト通知メールを自動取得します。

※ 通常のログインパスワードでは Google 仕様上接続できません。 Google アプリパスワード発行画面 で発行した16文字を入力してください。
方法②：Google OAuth 2.0 / Gmail API トークン連携
Google OAuth 2.0 で認証して Gmail 連携 Google OAuth 2.0 で連携（クライアントID設定時）
Gmail API アクセストークン（ya29...）を直接入力して連携
OAuth 2.0 Playground 等で https://www.googleapis.com/auth/gmail.readonly スコープのトークンを発行して貼り付けできます。
Web Push 通知許可ステータス: 確認中...

ブラウザの通知設定を確認しています。

取得対象と解析の仕組み

小テスト対応
1

実メールから自動抽出（ダミー投入なし）

ログイン時にご自身の Gmail から manaba / 小テスト 関連メールを検索し、実際の科目・小テストのみ登録します。

2

公開時間・締切時間の両方を解析

[受付開始日時]（公開時間）と [受付終了日時]（締切時間）、manaba URL を自動抽出します。

3

通知時刻と科目別 ON/OFF 設定

締切 24時間前・5時間前・1時間前など複数タイミングと、科目ごとの通知可否をカスタマイズできます。

4

メール本文貼り付けにも対応

アプリパスワードを使わない場合でも、ログイン後に manaba 通知メールの本文を貼り付けるだけで自動解析して登録できます。
