Google OAuth 2.0 / GAS × Web Push 連携

manaba の小テスト・課題締切を、あなたの Gmail から自動取得。

大学 Google アカウント（Google Workspace）でも安心して使える Google OAuth 2.0 と Google Apps Script (GAS) の2つの連携方式に対応しています。

方法①：Google アカウントでログイン（OAuth 2.0）

設定済み 初回設定が必要

詳細設計書準拠の Google OAuth 2.0（gmail.readonly スコープ）でログインし、 manaba の小テスト・課題通知メールを自動取得します（リフレッシュトークン自動更新対応）。

Google アカウントでログイン & Gmail 連携
初回のみ：Google OAuth 2.0 クライアントID / Secret を設定（再起動不要）
  1. Google Cloud Console で Gmail API を有効化
  2. 「OAuth 同意画面」（テストユーザーに自分のメールを追加）を設定
  3. 「認証情報」→「OAuth クライアント ID（ウェブ アプリケーション）」を作成し、承認済みのリダイレクト URI に以下を設定：
    http://localhost:8080/auth/callback
  4. 発行されたクライアント ID とシークレットを下に貼り付けて保存
OAuth 2.0 Playground アクセストークン（ya29...）で今すぐ試す
OAuth 2.0 Playground で https://www.googleapis.com/auth/gmail.readonly を認可してトークンを取得できます。

方法②：Google Apps Script (GAS) 連携

Google Cloud 設定不要

ご自身の Google アカウントで GAS スクリプトを1回デプロイするだけで、外部アプリ認証なしで自分の Gmail から manaba 小テストメールを取得できます。

GAS セットアップ手順＆1クリックコピー用コードを表示
  1. Google Apps Script (script.google.com) を開き、「新しいプロジェクト」を作成
  2. 下の「GASコードをコピー」を押してエディタに貼り付け、保存（Ctrl+S）
  3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選択し、アクセスできるユーザー：全員 にしてデプロイ → 表示されたウェブアプリ URL を下のフォームに貼り付け
    ※ 大学組織ポリシー等で「全員」が選べない場合は、GAS エディタ上で関数 exportManabaJson を実行し、ログに出力された JSON をログイン後の貼り付けモーダルに入れても取り込めます。 
const SYNC_TOKEN = 'manaba-sync-2026';

function collectManabaMessages() {
  const query = 'from:do-not-reply@manaba.jp OR manaba OR (小テスト (受付終了 OR 締切 OR コース))';
  const threads = GmailApp.search(query, 0, 50);
  const emails = [];
  for (const thread of threads) {
    for (const msg of thread.getMessages()) {
      emails.push({
        subject: msg.getSubject(),
        body: msg.getPlainBody(),
        date: msg.getDate().toISOString()
      });
    }
  }
  return {
    email: Session.getActiveUser().getEmail(),
    emails: emails
  };
}

function doGet(e) {
  const token = (e && e.parameter && e.parameter.token) ? e.parameter.token : '';
  if (token !== SYNC_TOKEN) {
    return ContentService
      .createTextOutput(JSON.stringify({ error: 'Unauthorized' }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  const payload = collectManabaMessages();
  return ContentService
    .createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}

// 組織制限等で「全員」公開ができない場合：エディタでこの関数を実行し、ログ出力をコピー
function exportManabaJson() {
  const payload = collectManabaMessages();
  Logger.log(JSON.stringify(payload));
}

取得対象と解析の仕組み

小テスト対応
1

実メールから自動抽出（ダミー投入なし）

Google OAuth 2.0 または GAS 連携で自分の Gmail から manaba / 小テスト メールを検索し、実データのみ登録します。

2

公開時間・締切時間の両方を解析

[受付開始日時]（公開時間）と [受付終了日時]（締切時間）、manaba URL を自動抽出します。

3

通知時刻と科目別 ON/OFF 設定

締切 24時間前・5時間前・1時間前など複数タイミングと、科目ごとの通知可否をカスタマイズできます。

4

メール本文・GAS JSON 貼り付け対応

組織制限で外部アクセスできない場合も、exportManabaJson() の出力 JSON やメール本文を貼るだけで一括登録できます。
